# Teinar.is — endurhönnun

Nýr static vefur fyrir [www.teinar.is](https://www.teinar.is).

Núverandi síða er WordPress. Markmiðið er að endurhanna hana sem hraðan,
öruggan static vef (enginn gagnagrunnur, bara HTML/CSS/JS).

- [ ] Skrapa innihald úr núverandi WordPress-síðu
- [ ] Ákveða uppsetningu og hönnun
- [ ] Byggja síðurnar
- [ ] Íslensk + ensk útgáfa
- [ ] Birta og færa teinar.is
